全功能覆盖

覆盖日常 Git 工作流的每一个环节，从初始化到推送，一站式完成

仓库管理

初始化新仓库、克隆远程仓库、打开本地已有仓库，一站完成仓库级操作。

init · clone · open

文件操作

暂存、取消暂存、丢弃更改、差异对比，文件状态一目了然。

add · reset · checkout · diff

提交管理

提交变更、查看历史、搜索记录、详情查看、回退与撤销，完整掌控每一次提交。

commit · log · show · reset · revert

分支管理

创建、删除、切换分支，合并代码，可视化管理分支拓扑。

branch · checkout · merge

远程操作

拉取、推送、获取远程更新，管理远程仓库配置，与团队协作无缝衔接。

pull · push · fetch · remote

暂存管理

快速保存工作现场、随时恢复，切换分支不再丢失未完成的修改。

stash push · stash pop

标签管理

在关键提交处创建标签、删除标签，精准标记版本里程碑。

tag · tag -d

内置终端

执行自定义 Git 命令，彩色输出实时反馈，保留完整命令历史。

自定义命令 · 彩色输出
